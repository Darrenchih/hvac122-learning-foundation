## 真實瀏覽器覆蓋

- 以本機 HTTP 載入，阻擋外部請求；已載入後開啟瀏覽器離線模式，練習與計分仍運作。
- 英文預設、中文顯示／隱藏、提交前不渲染解析、提交後雙語理由。
- 重新載入及實際關閉／重開瀏覽器程序後，作答、錯因與未完成階段保留。
- 模擬考交卷前不產生評分，交卷後保留所有紀錄。
- 真實檔案下載、學習備份 JSON 匯入還原、中文知識庫搜尋。
- 1440 px 桌面及 390 px 手機無橫向頁面溢出；實際截圖在同目錄。
- 真實管理表單建立題目、發布後練習頁載入 301 題。
- 原始附件存入 IndexedDB，關閉／重開瀏覽器後下載，與原輸入逐位元 SHA-256 相同。
- 控制台無腳本錯誤、無外部網路請求。示範資料為測試產生，不是真實私人學習紀錄。

## 修正過的測試問題

初始沙箱限制使瀏覽器無法啟動；取得允許本機網路測試的權限後執行。`file://` 在本次瀏覽器環境受管理政策阻擋，因此改測工具正式支援的本機 HTTP 入口；沒有繞過該政策宣稱檔案模式已通過。

真實操作揭露測試在管理頁跳回練習頁後過早讀取全域資料，以及「開始練習」和側邊導覽的相同屬性造成定位歧義。測試改等待練習頁載入並精確選擇導覽按鈕，回歸通過；未把測試定位錯誤冒稱產品資料損壞。

公開版以「不包含私人原始教材／壓縮檔」檢查取代私用交付的原 ZIP 逐位元比較；不需要私人附件即可重建。原始課程／教學專家核對仍未完成，程式驗收不取代來源核對。

CI 已提供 Linux 單元及真實 Chromium 流程。GitHub Actions 的線上狀態仍以實際執行結果為準。重跑時生成的 logs／JSON 不納入公開版本。

## 線上 CI 回歸

線上較快的檔案選擇動作暴露管理頁初次讀取附件清單時重畫整頁的競態，可能移除正在操作的檔案輸入並遺失未儲存筆記。改成只更新附件清單及錯誤區，不重建表單／輸入，並新增延遲清單回覆時保留未儲存表單的回歸測試。
